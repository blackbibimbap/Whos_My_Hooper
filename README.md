# _Whos_My_Hooper_🏀

### NBA Shot Chart Analytics Project
Turn an NBA dataset into a shot chart visualization to explore
player shooting patterns and performance.

## Project Overview 
The goal is to build a Python-based application that processes
NBA shot data and generates visual shot charts.

Users will be able to explore player shooting locations,
identify made and missed shots, and analyze shooting performance.

The project follows Agile Scrum methodology and consists
of two development sprints.

## Core Features(expected)

### 1. Player selection
Users can select an NBA player and retrieve their shooting data for analysis.

### 2. Interactive shot chart
Visualize individual shot attempts on a basketball court using shot location coordinates.

### 3. Shooting performance analysis

Analyze player performance using statstis such as:
Field goal Percentage, Shot attempts and makes,Shooting percentage by distance, Shooting efficiency,Shot freqeuncy

### 4. Data Filtering

Filtering options such as:
Player, Game, Season, Quarter, Shot zone
